## PURPOSE

Freeze explicit source-Fourier loop-momentum assignments for the already-authorized SF055A3 A3.2 baseline topologies. This note does not change topology coefficients, propagators, regulator, external kinematics, projection, quadrature criteria, or baseline PASS thresholds.

Use incoming momentum convention at every vertex. External momenta obey

`p1+p2+p3=0`.

A single independent loop coordinate is denoted `q`. Routing-equivalent affine shifts of q are consistency checks only and may not be used to fit the published baseline.

## T5_GRAV — five-vertex tadpole

Canonical five-vertex incoming momenta:

`[p1,p2,p3,q,-q]`.

The regulated differentiated internal line is the q/-q pair.

Mandatory conservation:

`p1+p2+p3+q-q=0`.

## B43_GRAV — four/three bubble

For canonical external assignment `(p1,p2 | p3)`, define

four-vertex:

`V4: [p1,p2,q,-q-p1-p2]`,

three-vertex:

`V3: [p3,-q,q+p1+p2]`.

The two internal line pairs are therefore

`q <-> -q`

and

`-q-p1-p2 <-> q+p1+p2`.

Using `p1+p2=-p3`, the second internal momentum is equivalently `-q+p3` on V4 / `q-p3` on V3.

External symmetrisation is generated mechanically over all permutations of `(p1,p2,p3)`; no manually distinct numerical kernel is permitted for a permutation-related assignment.

## T333_GRAV — graviton triangle

Orient the three internal edges as `e12`, `e23`, `e31`. For canonical external ordering `(p1,p2,p3)`, set

`e12 = q`,

`e23 = q-p2`,

`e31 = q+p1`.

Incoming vertex momenta are

`V1: [p1, q, -(q+p1)]`,

`V2: [p2, -q, q-p2]`,

`V3: [p3, -(q-p2), q+p1]`.

Each vertex must sum to zero independently. The same routing is used for the ghost triangle with graviton internal tensors replaced by the source FP ghost objects.

External symmetrisation is again generated mechanically over all permutations.

## T333_GHOST — ghost triangle

Use the same graph-level affine internal momenta as `T333_GRAV`. Ghost-arrow orientation must be chosen once in code and kept fixed; reversing the entire closed ghost loop is a routing-equivalent representation, not an extra topology. The overall source coefficient remains the already-frozen `+6` and must not be recomputed from routing multiplicity.

## ROUTING-SHIFT CONSISTENCY

Before numerical integration, the implementation must support replacing the canonical loop coordinate by

`q -> q + a1 p1 + a2 p2`

with integer diagnostic shifts `(a1,a2)` in

`{(0,0),(1,0),(0,1),(-1,0),(0,-1)}`

and mechanically regenerate all internal edge momenta from the shifted coordinate.

Required pre-integration controls:

1. every vertex conserves momentum to absolute norm <= `1e-12` for deterministic dense external/source controls;
2. every internal edge appears at its two incident vertices with exactly opposite momentum;
3. external permutation generation produces the expected 6 labelled assignments before any symmetry reduction;
4. no topology coefficient changes under routing shifts or external permutations;
5. no new topology is generated by a loop-coordinate shift;
6. for scalar diagnostic test integrands with translation-invariant full-space measure, algebraically shifted routings agree after the corresponding variable substitution; this is a code-path diagnostic, not a claim that a hard cutoff permits arbitrary unaccounted shifts.

## REGULATOR CAUTION

The optimized FRG regulator depends on the momentum carried by the differentiated internal line. Therefore a naive numerical shift of q while holding the regulator argument fixed is NOT a valid routing-equivalence test. The differentiated line and every shifted propagator/regulator argument must transform together with the routing map.

`LOOP_ROUTING_EQUIVALENCE != HOLD_REGULATOR_ARGUMENT_FIXED_WHILE_SHIFTING_OTHER_LINES`.

## NEGATIVE CONTROLS

The routing checker must reject:

- one sign-flipped internal endpoint;
- a bubble V3 momentum using `q-p1-p2` instead of `q+p1+p2`;
- a triangle edge that is not opposite at its two endpoints;
- loss of one external permutation;
- duplication of a permutation counted as a new topology;
- mutation of a source coefficient during symmetrisation;
- a routing-shift implementation that moves propagator momenta but leaves the differentiated regulator line frozen.

## INTERPRETATION CEILING

Passing this routing gate validates only graph momentum bookkeeping. It does not validate tensor contractions, symmetry factors beyond the inherited Lane-C coefficients, regulator differentiation, loop integration, Eq. (14), Lane A, or any C3 flow.
