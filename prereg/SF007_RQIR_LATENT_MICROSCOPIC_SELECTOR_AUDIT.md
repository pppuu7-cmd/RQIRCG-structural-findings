## What counts as a microscopic selector

A frozen RQIR object counts as a selector only if it supplies, or logically entails within its declared scope, enough information to determine at least one of the following equivalent kinds of object:

1. physical microscopic degrees of freedom plus their spectrum;
2. a microscopic state space and state-generation/evolution law;
3. a complete spectral/measure rule fixing the matching data relevant to the homogeneous nonlinear sector;
4. a boundary/fixed-point principle that selects those data;
5. an equivalent complete generating object from which nonlinear Wilson/matching coefficients follow without free phenomenological choices.

A generic instruction to be relational, covariant, unitary, causal, positive, falsifiable, minimal, comparator-resistant, or consistent does **not** count unless RQIR itself supplies the missing derivation from that instruction to the microscopic data.

## Positive criterion

If frozen RQIR contains such a rule, the gate returns

`RQIR_CONTAINS_LATENT_MICROSCOPIC_SELECTOR_SCOPED`

and records the exact authoritative text/provenance plus the next derivation required before any connected-observable calculation.

## Negative criterion

If the authoritative RQIR requirements explicitly define an interface/observable/consistency programme while leaving microscopic ontology/dynamics/spectrum unspecified, or if every candidate selector found is only a constraint on an otherwise free completion, the gate returns

`RQIR_FROZEN_REQUIREMENTS_DO_NOT_SELECT_MICROSCOPIC_GENERATING_DATA_SCOPED`.

This is not a claim that no deeper principle exists. It means only that the currently frozen RQIR judge does not contain it.
