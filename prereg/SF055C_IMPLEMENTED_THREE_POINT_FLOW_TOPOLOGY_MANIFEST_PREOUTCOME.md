## STRUCTURAL DERIVATION TO BE CHECKED

Let `G=(Gamma^(2)+R)^(-1)` and take the regulator to carry no fluctuation-field C3 vertex in the frozen flat-background setup. For a bosonic fluctuation derivative,

`delta G = -G (delta Gamma^(2)) G`.

Three external graviton derivatives of the bosonic trace must reduce, after external symmetrization and cyclic trace equivalence, to:

1. one graviton 5-vertex tadpole class with coefficient `-1/2`;
2. one graviton 4/3 bubble class with coefficient `+3`;
3. one graviton 3/3/3 triangle class with coefficient `-3`.

The classical Faddeev-Popov sector in the source linear gauge contributes the ghost triangle class with coefficient `+6`.

The coefficient check is frozen algebraically as

- boson tadpole: `(1/2)*(-1) = -1/2`;
- boson 4/3: `(1/2)*(+6) = +3`;
- boson 3/3/3: `(1/2)*(-6) = -3`;
- ghost 3/3/3: `(-1)*(-6) = +6`.

If the source/derivative structure does not support this exact mapping, classify BLOCKED/INVALID rather than remapping after outcome inspection.
